その壁の外側で

03

生身の距離

DEFAULT NAME : 久我 霞 / NAME SETTING

「次。爆豪、久我」

相澤に名前を呼ばれ、霞は顔を上げた。少し離れたところで爆豪も立ち上がる。

「爆豪くんか」

「あ？」

「ううん。よろしくね」

「足引っ張んな」

「そっちもね」

「テメェが俺の心配すんな」

始まる前からこれである。霞は特に気にした様子もなく、支給されたプロテクターを腕へつけながら爆豪の隣を歩いた。

今回の演習は二人一組で指定地点まで進み、妨害を突破して最奥の端末へ触れるものだった。演習場には自動砲台や障害物が配置されており、一定以上の被弾で失格になる。

待機地点に着いたところで、霞はふと思い出したように口を開いた。

「爆豪くん」

「何だ」

「近くに味方いたら、爆発って弱める？」

爆豪が怪訝そうな顔で振り向いた。

「は？」

「威力。あと向きとか」

「何でテメェに教えなきゃなんねぇ」

「バリア出すタイミング決めたいから」

霞は自分の手をひらひらさせた。

「爆豪くんが避けられる攻撃まで私が止めたら邪魔でしょ。逆に、爆発するために避けたくない時だけ守ればいいかなって」

爆豪の眉が少し動いた。

「俺の動き見て判断しろ」

「要求高いなあ」

「雄英だぞ」

「便利だね、その言葉」

爆豪は鼻を鳴らす。霞は少し考えて、もう一つ聞いた。

「じゃあ、私が近くにいる時は？」

「テメェの位置くらい見て撃つわ」

「やっぱ見るんだ」

「当たり前だろが」

苛立ったように言ってから、爆豪は演習場の方へ顎をしゃくった。

「味方巻き込んで最大火力ぶっ放すだけなら、ただの馬鹿だろ」

霞が瞬きをした。何か言おうとしたところで、開始を知らせるブザーが鳴る。

「行くぞ！」

「あ、待って！」

待ってくれるはずもなく、爆豪は爆発とともに飛び出した。

爆豪と組んで最初に分かったのは、思っていた以上にこちらが忙しいということだった。

速い。とにかく速い。前方から飛んできた演習弾を爆破で逸らしたと思えば、その反動でもう数メートル先にいる。霞も走って追いながら、爆豪の進路と周囲の砲台を同時に見る。

右から二発。これは避ける。正面から一発。爆豪が掌を前へ向けた。撃ち返すつもりだ。

「そこ！」

霞が手を上げた。爆豪の横にバリアが現れ、死角から飛んできた一発だけを弾く。直後には消す。

爆発。爆豪は一度も足を止めず、正面の砲台を吹き飛ばした。

「おお」

「何見物してんだ！」

「ちゃんとやってるよ！」

言い返した瞬間、霞のすぐ横を演習弾が通過した。

「危な」

慌てて身体を沈める。また一発。今度は横へ。

爆豪の速度へ合わせながらとなると、普段より見る場所が多い。爆豪。自分。敵。次の攻撃。一枚しかないバリアをどこへ置くか。

霞が前方を確認した瞬間、左の砲台が大きく開いた。今までより広い範囲へ、一斉に弾がばら撒かれる。

「うわ」

爆豪は進路を変えない。霞は反射的に彼へバリアを張った。連続した衝撃が透明な表面を叩く。

そのまま霞自身は走って避けた。一発。二発。三発目が頬を掠める。

「っ」

ぴり、と熱い痛みが走った。それでも足は止めない。広範囲攻撃が終わると同時にバリアを消す。

次の瞬間、爆豪の爆発が砲台をまとめて吹き飛ばした。煙の中から声が飛ぶ。

「久我！」

「何！」

「そこいろ！」

指差された先を見る。演習用の壁が作る小さな窪みだった。正面以外からの射線がほとんど通らない。

「でも――」

「そこから届くだろ！」

霞は口を閉じた。確かに届く。爆豪を守るには十分な距離だ。霞自身が動き回らなければならない理由はない。

「分かった！」

窪みへ入る。そこから先は早かった。

霞がやったのは二回だけだ。一度、爆豪の背後から飛んだ弾を防いだ。もう一度、爆豪が真正面へ突っ込む時に壁を作った。それだけ。

爆豪はほとんど一人で残りの妨害を潰し、あっという間に最奥の端末へ手を叩きつけた。

ピーッ――！

終了のブザーが鳴る。

霞は窪みから顔を出した。

「……速」

「遅ぇ」

「私まだ何にもしてない気がする」

「二回やっただろ」

「数えてたの？」

「見てりゃ分かるわ」

爆豪がこちらへ歩いてくる。途中で、ぴたりと視線が止まった。

霞は首を傾げる。

「何？」

「頬」

「あ」

触ってみる。指先へ、ほんの少し赤いものがついた。

「あー。さっきのか」

「食らってんじゃねぇか」

「掠っただけだよ」

「食らってんだろが」

「同じこと二回言ってる」

爆豪の額に青筋が浮いた。

演習後。

霞はベンチへ座り、小さな救急セットから絆創膏を取り出していた。鏡代わりにスマートフォンの画面を使ってみるが、傷の位置が微妙に分かりづらい。

右。違う。もう少し上。

「……貼りにく」

「貸せ」

「え？」

横から手が伸び、絆創膏を奪われた。爆豪だった。

「爆豪くん？」

「動くな」

「自分でできるよ」

「できてねぇだろ」

反論する前に、頬へぺたりと貼られた。雑だ。しかし位置は完璧だった。

「ありがと」

「次食らったらぶっ飛ばす」

「それ怪我増えるじゃん」

「避けろっつってんだよ！」

霞は笑いながら頬を押さえた。少し間を置いて、隣に立つ爆豪を見る。

「爆豪くんって、思ってたより戦いやすいね」

「あ？」

「褒めてるよ」

「聞こえねぇな」

「面倒くさいなあ」

爆豪が睨む。霞は気にせず続けた。

「火力すごいのは知ってたけど、もっと周り関係なくドカドカやる人かと思ってた」

「殺すぞ」

「まだ最後まで言ってないって」

霞は苦笑した。

「私がいる方には破片飛ばさないし、私がバリア消すまでちゃんと爆発の向き変えてたでしょ」

爆豪が黙る。

「結構細かく見てるんだなって」

「当たり前のこと褒めんな」

「当たり前？」

「あ？」

「だって、あれだけ火力あったら、最大で撃った方が楽じゃん」

「味方まで吹っ飛ばして勝って何になんだよ」

即答だった。

霞は少しだけ目を丸くした。演習前にも似たことを言っていた。味方を巻き込んで最大火力を出すだけなら馬鹿だ、と。本当にそう思っているらしい。

勝つことにあれだけ拘っているのに、その「勝ち」の中には最初から、味方を無事に残すことまで入っている。

「……そっか」

「何だよ」

「いや」

霞は笑った。

「そういうの、いいね」

爆豪の眉が寄る。

「何が」

「ちゃんと自分の力、自分で扱ってる感じ」

「テメェに言われるまでもねぇ」

「うん。でも知らなかったから」

霞は素直に言った。

「今日知った」

爆豪は何も返さなかった。代わりに霞の頬へ貼った絆創膏を見る。

「で、テメェは」

「私？」

「人のこと見てる暇あんなら、自分の位置も見ろ」

「あれは避け損ねただけだって」

「同じだ」

「厳しいなあ」

「バリア一枚しかねぇんだろ」

霞が目を上げる。

爆豪は面倒そうな顔のまま続けた。

「俺に使うなら、その間テメェは生身だ。だったら食らわねぇ前提で動け」

「……うん」

「できねぇならやんな」

霞は一瞬黙った。けれど、その言葉に嫌な感じはしなかった。

やめろ、と言われたわけではない。危ないから後ろへいろとも。お前には無理だとも。

できるならやれ。やるなら、できるようになれ。ただそれだけだ。

「じゃあ、もっと練習する」

「勝手にしろ」

「爆豪くんにもまた付き合ってもらおうかな」

「あ？」

「今日、すごい練習になったし」

「断る」

「即答」

霞が笑う。

爆豪は苛立った顔で立ち去ろうとして、数歩進んだところで止まった。

「次」

「ん？」

「張るなら半拍早くしろ。二回目遅ぇ」

霞は瞬きをした。それから、にやっと笑う。

「次あるじゃん」

「うるせぇ！」

爆豪は今度こそ振り返らずに歩いていった。

霞はその背中を見送りながら、頬の絆創膏に触れた。

怖いし、口は悪いし、すぐ怒鳴る。その認識は別に変わっていない。

ただ。

思っていたよりずっと、話の通じる人なのかもしれない。

一方、廊下へ出た爆豪は舌打ちしていた。

攻撃力はない。自分を守る個性でもない。なのに必要なところへ壁を置き、邪魔になる寸前には消す。

しかも、こちらが何をしているのかまで妙に正確に見ている。ただ「すごい」と騒ぐ連中とは違う。

爆豪は眉間に皺を寄せたまま、頬に小さな傷を作った女の顔を思い出した。

次は半拍早く。

そう言えば、あの女はたぶん本当に合わせてくる。

それがなぜか、少しだけ楽しみだった。
